# v0.5.2

## 概要

`session-manager-custom` 0.5.2 整理公开仓库目录、重命名 GitHub 仓库并同步安装地址，不改变插件功能或 DSH 外部接口。

## 变更

- Host/Client 入口移至 `lib/`，公开包使用 `lib/index.js` 和 `lib/client.js`。
- GitHub 社区文件归入 `.github/`，项目说明与版本元数据归入 `docs/`。
- GitHub 仓库由 `dsh-plugin-session-manager-custom` 重命名为 `dsh-plugin_session-manager-custom`，公开安装地址、README 和 Release 正文同步更新。
- 安装脚本只从公开仓库根目录解析 `package.json` 和 `cordis.patch.yml`，移除了旧的嵌套布局支持。
- 公开仓库根目录保留 DSH 包入口、README、LICENSE，以及仓库自身的 `.gitattributes`、`.gitignore`；其他公开内容进入对应子目录。
- 为 `scripts/install.ps1` 添加 UTF-8 BOM，确保 Windows PowerShell 5.1 正确解析。
- 新增可脱离仓库独立运行的 `scripts/uninstall.ps1`：脚本内置稳定包名，先按官方 DSH 规范卸载 Profile 中的插件，再清理插件自身的备份区和回收站目录；支持从私有 GitHub 仓库下载到临时文件后运行，安装过程产生的 tarball 缓存不由卸载脚本处理。
- README 和本 Release 说明补充公开仓库的在线卸载命令；固定到 `v0.5.2` 的命令会在内存中移除 UTF-8 BOM，不会在当前工作目录留下脚本文件，但会执行插件卸载及运行时数据清理。

## 安装

```powershell
dsh plugin --profile web add github:FloatingLifeTL/dsh-plugin_session-manager-custom#v0.5.2
```

本地安装或更新：

```powershell
.\scripts\install.ps1
```

## 卸载

本地运行仓库中的卸载脚本：

```powershell
.\scripts\uninstall.ps1
```

公开仓库也可以以内存方式执行发布版本的脚本，默认操作 `web` profile：

```powershell
iex ((irm 'https://raw.githubusercontent.com/FloatingLifeTL/dsh-plugin_session-manager-custom/v0.5.2/scripts/uninstall.ps1').TrimStart([char]0xFEFF))
```

该命令会执行官方 DSH 插件卸载，并在没有其他 profile 使用本插件时删除插件备份区和回收站数据；安装过程产生的 tarball 缓存和迁移备份目录不会由卸载脚本处理。运行前请确认相关会话数据不再需要保留。

## 兼容性
